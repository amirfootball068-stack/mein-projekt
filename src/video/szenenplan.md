# Szenenplan

Eine Zeile im Skript = eine Szene. Pro Szene ein Satz: was man sieht, und was auf welchem Wort passiert.
Claude macht daraus die Kamera-Tabelle in MeinVideo.tsx.

Voice-over: „Voiceover_neu.mp3“ (21,9 s). Das vorige Video (Zucker-Version) liegt im Git-Verlauf.

Gefäß: breite Glasschale – man sieht das Açaí durchs Glas, die Toppings liegen in Reihen oben drauf (Erdbeeren | Blaubeeren | Banane | Granola). Jede Zutat erscheint über ihrer Reihe.
Zutaten: jede erscheint auf ihrem Wort groß mit Namen und kippt dann in die Schale.
Farben: Weiß = Welt und Figur · Violett = Açaí · Gold = Schlüsselwörter, Sonne, Glanz · Toppings in ihren echten Farben (Erdbeere rot, Blaubeere blau, Banane hell).

| # | Skriptzeile | Was man sieht | Aktion auf Wort | Einstellung |
|---|---|---|---|---|
| 1 | Deine Açaí-Bowl ist mehr als ein hübsches Frühstück. | Glasschale mit Açaí fällt ab dem ersten Bild herein, Funkeln rund um die Schale, Fähnchen „FRÜHSTÜCK“ steckt sich hinein, die Figur hüpft | Schale landet auf „Açaí-Bowl“, Rückfahrt auf „mehr“, Funkeln auf „hübsches“, Fähnchen auf „Frühstück“ | nah → halbnah → nah |
| 2 | Cremig, fruchtig, eiskalt. | Cremiger Strudel dreht sich auf dem Açaí, Fruchtstücke hüpfen heraus, dann wird die Schale eisig: Eiskristalle am Glas, kalter Nebel, die Figur zittert | je ein Effekt auf „Cremig“, „fruchtig“, „eiskalt“ | nah → halbnah → halbnah mit Figur |
| 3 | Obendrauf Erdbeeren, Blaubeeren, Banane. | Erdbeerschale, Blaubeerschale und Banane erscheinen nacheinander mit Namen und kippen hinein, oben legen sich die Toppings in Reihen | Schnitt auf „Obendrauf“, je eine Zutat auf „Erdbeeren“, „Blaubeeren“, „Banane“ | halbnah → nah |
| 4 | Und Granola, das beim ersten Löffel knackt. | Granola-Tüte kippt hinein, ein Löffel taucht ein, „knack“: Lichtblitz, Krümel springen, Bild wackelt kurz, die Figur hüpft | Granola auf „Granola“, Löffel auf „Löffel“, Knack auf „knackt“ | halbnah → nah |
| 5 | Morgens als Start in den Tag. | (nächstes Stück) | | |
| 6 | Nachmittags als kleiner Snack. | (nächstes Stück) | | |
| 7 | Abends als Belohnung nach einem langen Tag. | (nächstes Stück) | | |
