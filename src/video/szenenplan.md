# Szenenplan

Eine Zeile im Skript = eine Szene. Pro Szene ein Satz: was man sieht, und was auf welchem Wort passiert.
Claude macht daraus die Kamera-Tabelle in MeinVideo.tsx.

Farben: Weiß = Welt und Figur · Violett = Açaí · Gold = Zucker (auch die Schlüsselwörter im Untertitel).

| # | Skriptzeile | Was man sieht | Aktion auf Wort | Einstellung |
|---|---|---|---|---|
| 1 | Deine Açaí-Bowl ist ein Dessert. | Violette Bowl auf dem Boden, Figur daneben. Ein Fähnchen „DESSERT“ steckt sich in die Bowl | Kamera zieht auf „ist“ auf, Fähnchen plopp auf „Dessert“ | nah → halbnah |
| 2 | Die Beere selbst schmeckt kaum süß, eher erdig. | Eine einzelne Beere fällt vor die Figur. Ein Messgerät „SÜSSE“ zeigt fast nichts | Beere landet auf „Beere“, Messgerät auf „kaum“, Figur kippt (Zweifel) auf „erdig“ | nah → halbnah |
| 3 | Darum ist das Püree im Laden oft gesüßt. | Regal mit Schild „LADEN“ und einem Püree-Beutel. Zuckerwürfel fallen in den Beutel, Zähler „ZUCKER“ springt hoch | Schnitt auf „Darum“, Fahrt zum Beutel auf „Püree“, Zucker fällt auf „gesüßt“ | Totale → halbnah → nah |
| 4 | Obendrauf Banane, Granola, Honig. | Zurück zur Bowl: Bananenscheiben, Granola und ein Honigfaden fallen hinein, der Zähler steigt bei jedem Topping | Schnitt auf „Obendrauf“, je ein Topping auf „Banane“, „Granola“, „Honig“ | halbnah → nah |
| 5 | Am Ende löffelst du eine Schale voller Zucker. | (nächstes Stück) | | |
| 6 | Besser ungesüßtes Püree, Naturjoghurt, frische Beeren. | (nächstes Stück) | | |
| 7 | Frühstück oder Dessert? Was ist deine Bowl? | (nächstes Stück – letztes Bild = erstes Bild) | | |

Beispiel (aus „Ein Prozent am Tag“):

| # | Skriptzeile | Was man sieht | Aktion auf Wort | Einstellung |
|---|---|---|---|---|
| 2 | Jeden Tag ein Prozent besser. | Münze fällt auf den Sockel, Zähler springt auf 1,01 | Münze landet auf „besser“ | halbnah |
| 3 | Klingt nach nichts. | Zähler läuft bis Tag 7, Figur kippt zweifelnd | Kamera fährt auf „Klingt“ nah an den Zähler, auf „nichts“ zurück zur Figur | nah → halbnah |
